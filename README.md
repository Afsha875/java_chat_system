# Java_Projects

This is a basic chat system project where two user interfaces can chat simultaneously. I developed this project during my early academic years to explore network communication and simultaneous response handling in Java. </br>
The chat application introduces both ends simultaneous response </br>

How to run: </br>
1. Open in Vscode/ other ides
2. Run java server.java
3. Run java client.java
